■ 4. Card getter方針
==================================================

F-3Aでは、

CardMaster
と
Card

を分離します。


ただし既存GameEngine等では、

card.name
card.cardType
card.level
card.cost
card.color
card.basePower
card.baseSoul

等を直接参照しています。


F-3AではCardにgetterを設け、

Card内部ではCardMasterを参照しながら、

既存コードからは可能な限り

card.level
card.cost
card.color

等のAPIを維持する方針とします。


この方針を設計書へ明記してください。

■ 8. Card
==================================================

Cardは対戦中の1枚のinstanceです。


概念：


Card {
  instanceId,
  masterId,

  owner,
  zone,
  row,
  index,
  face,
  position,

  currentPower,
  currentSoul,
  visibilityOverride
}


固定情報はCardMasterへ移します。


ただしgetterによって、

card.name
card.level
card.cost
card.color
card.cardType

等を既存コードから参照可能にする方針です。
