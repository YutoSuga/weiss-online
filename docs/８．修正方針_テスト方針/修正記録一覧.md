# 修正記録一覧

## 運用方針

- 記録対象、作業順、設計書との責務分離の詳細は[修正記録の運用ルール](README.md)に従う。
- 追跡価値のある修正では「修正方針」「修正結果」のMarkdownファイルを作成・更新し、本一覧も併せて更新する。
- 本一覧を修正記録の管理台帳とし、Phase・修正単位ごとに作業順で記載する。
- 修正方針には目的・対象範囲・制約・確認項目を、修正結果には変更内容・確認結果・未対応事項を記録する。
- 未作成の記録は「未作成」と記載し、作成後にリンクへ更新する。
- ファイル名や配置を変更した場合は一覧のリンクも更新し、リンク先が存在することを確認する。
