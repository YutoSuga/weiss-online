==================================================
■ 8. 枠を超える場合のみ動的圧縮
==================================================

通常offsetで全Stockカードを表示した結果、

Stock Zoneの利用可能高さを超える場合のみ、

全カードがZone内に収まるよう
offsetを動的に圧縮してください。


概念的には、

normalOffset = 通常の重なり幅

availableStackSpace
= Stock Zone内で重ね表示に使える高さ

requiredStackSpace
= cardHeight + (cardCount - 1) * normalOffset


requiredStackSpace <= availableStackSpace

→ normalOffsetを使用


requiredStackSpace > availableStackSpace

→ 全カードが収まるoffsetへ圧縮


という考え方です。


具体的な計算方法は、
現在のDOM / CSS / Renderer構造に合わせて実装してください。
