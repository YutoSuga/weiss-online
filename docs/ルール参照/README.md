本プロジェクトは原則として上記の固定版を実装根拠とする。「常に最新URLの内容へ追随する」運用にはしない。公式PDFそのものは著作物かつ版管理の責務外であるためGitへ保存せず、版、更新日、条文、要旨、実装上の意味、関連設計、確認日だけを保持する。

## 新版公開時の正式運用

```text
公式新版公開 → 旧採用版との差分確認 → weiss-onlineへの影響調査
  ├─ 影響なし → 参照版・確認記録を更新
  └─ 影響あり → 設計・チェックシート変更 → 実装 → 回帰テスト
                  → 「総合ルール ver.x.x対応」の別タスク / PR
```

新版公開だけを理由に既存ゲーム仕様を自動変更しない。影響なしの場合も、確認した条文と判断を参照メモに残す。影響ありの場合は通常の仕様変更としてレビュー可能な別PRで取り込む。
