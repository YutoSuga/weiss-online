# UI操作.md

# UI操作仕様

## 概要

本ドキュメントは、プレイヤーがプレイ画面上で行う操作、および各操作に対するUIの振る舞いを定義する。

本仕様はPC版を対象とする。

---

# 基本方針

* 直感的な操作を目指す
* 実際のカードゲームに近い操作感を再現する
* 不要な確認ダイアログは極力表示しない
* 誤操作しにくいUIを目指す

---

# カード操作

## 右上カード詳細

閲覧者に公開された選択Cardについて、画像、名前、種類、色、Level、Cost、現在Power、現在Soul、Trigger Icons、Traits、Abilitiesを表示する。cardNumber、masterId、instanceIdおよびlegacyなCardMaster.textは表示しない。能力はCardAbilityのtypeを`CONTINUOUS → 【永】`、`AUTO → 【自】`、`ACT → 【起】`へ変換し、その`text`を続ける。0件は共通の空表示、複数件は順に表示する。

画像は「画像」という見出し列を持たない詳細先頭の独立ブロックとする。読み込み成功時は固定高さを予約せず、`width: 100%`、`max-width: 100%`、`height: auto`と`object-fit: contain`により縦長・横長の向きとアスペクト比を保ったまま全体を表示する。画像URLが`null`またはロードに失敗した場合は、画像用の高さを残さず、URLやファイル名を含まない一行程度の「画像なし」placeholderを表示する。非公開Cardは画像も詳細情報も表示しない。

MAINでの手札Card選択は「詳細を見るための選択」であり、「プレイできる」こととは区別する。自分のターンの`MAIN_PHASE / WAITING_INPUT`中に自分の手札にあるCardは、cardTypeに関係なく選択できる。Level・Color・Cost条件を満たさないCHARACTERも詳細を表示し、従来どおりプレイ不可理由を表示する。CLIMAXも詳細を表示できるが、Stage Destinationは表示せず、MAINからのプレイ処理は持たない。この選択可否はMAIN以外や相手ターンに一般化しない。

## 選択

### 左クリック

カードを選択状態にする。

選択されたカードは枠線や影などで強調表示する。

---

## 移動

カードをクリックまたはタップして選択し、ActionまたはDestinationを選択して移動する。

移動可能なDestinationだけを選択候補として強調表示し、有効なDestinationを選択した場合のみ移動を確定する。

カードを選択しただけでは自動実行しない。カード由来のActionはカード詳細パネルで選択し、配置・移動先が必要なActionはDestinationを明示的に選択する。

---

## 拡大表示

ダブルクリックでカードを拡大表示する。

拡大表示中は背景を暗くし、もう一度ダブルクリックまたはEscキーで閉じる。

# 手札

カードを選択して、Actionまたは移動先を選択する。

手札内の並び替えは未実装。

手札表示はGameStateの実枚数に同期し、8枚目以降も省略しない。
7枚以下は従来のカードサイズと配置を維持する。既存の最小デスクトップ盤面では
カードサイズとgapを維持したまま安全に収まる12枚分（896px）まで手札エリアを中央から拡張し、
13枚目以降は最大幅を維持して手札エリア内だけを横スクロールする。
相手の手札は従来どおり裏向き表示とする。

### 共通カード選択状態

選択操作を行うControllerは、理由に依存しない次の共通CSSクラスをカード枠へ付与する。

- `.is-selectable`: 有効候補。青い強調、hover反応、pointerカーソル。
- `.is-unselectable`: 選択範囲内だが無効な候補。軽く減光し、defaultカーソル。
- `.is-selected`: 選択済み。黄色の既存選択表示を使用し、他の候補表示より優先する。

Controllerが候補判定とクラスの付け外しを担当し、CSSは判定理由を持たない。選択操作終了時は全クラスを除去し、通常表示へ戻す。

# 操作ポリシー

* 操作回数はできるだけ少なくする。
* よく使う操作はワンクリックで実行できるようにする。
* 対戦テンポを妨げないUIを目指す。
* 実際のカードゲーム経験者が違和感なく操作できることを重視する。
