# 設計書ガイド

## 目的

本書を恒久設計書の正式な入口とする。知りたい責務から正本へ到達できるよう、設計書を実装Phase順ではなく「システム共通」と「対戦画面」に分け、対戦画面内をUI、フェイズ、カード能力に分類する。
